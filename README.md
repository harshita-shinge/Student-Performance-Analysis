# Student Performance Analysis

## Project Overview

This project analyses students' academic performance in Mathematics, Reading, and Writing using Python. It explores different factors that may be associated with student performance and presents insights through data analysis and visualisations.

## Objectives

* Analyse average marks across different subjects.
* Compare academic performance based on gender.
* Study the relationship between test preparation and student scores.
* Analyse performance based on parental education.
* Identify correlations between subject scores.
* Classify students into performance categories.

## Dataset

The project uses the Students Performance in Exams dataset, containing 1,000 student records.

**Dataset Source:** [Kaggle – Students Performance in Exams](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

1. Data loading and exploration
2. Data cleaning and preprocessing
3. Subject-wise performance analysis
4. Gender-wise performance analysis
5. Test preparation analysis
6. Parental education analysis
7. Correlation analysis
8. Student performance classification
9. Data visualisation

## Key Findings

* Reading had the highest average score among the three subjects.
* Students who completed the test preparation course had higher average scores in all three subjects.
* Female students had higher average Reading and Writing scores, while male students had higher average Mathematics scores.
* Reading and Writing scores showed a very strong positive correlation.
* Most students were classified into the Good and Excellent performance categories using the project's defined thresholds.

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/harshita-shinge/Student-Performance-Analysis.git
   ```

2. Open the project folder:

   ```bash
   cd Student-Performance-Analysis
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Download `StudentsPerformance.csv` from the Kaggle dataset linked above and place it in the project folder.

5. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

6. Open `Student_Performance_Analysis.ipynb` and run the cells.
